# OptiPlotCreator

## Назначение
OptiPlotCreator визуализирует системы линейных неравенств двух переменных и помогает анализировать допустимую область. Приложение строит границы полупространств, подсвечивает зону пересечения и показывает целевую функцию F = a·x₁ + b·x₂ вместе с LaTeX-представлением введённых формул.

## Требования
- macOS или Linux с графическим окружением
- Python 3.10+
- Установленные инструменты разработки для macOS: `xcode-select --install`

## Запуск из исходников
```
cd path/to/OptiPlotCreator
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
python3 main.py
```

## Сборка .app для macOS
```
source .venv/bin/activate
pyinstaller OptiPlotCreator.spec
```
Готовый бандл находится в `dist/OptiPlotCreator.app`. Перед распространением на другие машины выполните codesign/нотарификацию.

## Обзор интерфейса
- **Неравенства**: список редакторов с коэффициентами `a`, `b`, правой частью `c` и выбором оператора (`<`, `<=`, `>`, `>=`, `=`). Кнопка `Добавить` создаёт новый элемент, `✕` удаляет текущий.
- **Диапазоны отображения**: четыре поля задают границы по осям (`x₁ min/max`, `x₂ min/max`). Значения приводятся к возрастанию автоматически.
- **Функция F**: два коэффициента формируют вектор целевой функции; подпись обновляется в реальном времени.
- **LaTeX отображение**: предпросмотр системы неравенств и целевой функции в синтаксисе LaTeX.
- **Изображение**: кнопка `Сохранить график…` экспортирует текущее построение в PNG/JPEG/PDF/SVG.
- **Конфигурация**: импорт и экспорт набора параметров в файл `.cfg`/`.json`, пример структуры приведён в подсказке внутри окна.

## Пошаговое руководство по построению
1. Добавьте одно или несколько неравенств. Для каждого задайте коэффициенты `a`, `b`, правую часть `c` и выберите знак. Изменения сразу отражаются на графике.
2. Настройте область отображения, скорректировав минимальные/максимальные значения по осям. Это помогает приблизить нужный фрагмент или расширить поле.
3. Укажите коэффициенты целевой функции в блоке `Функция F`. Линия уровня и текстовое представление обновляются моментально.
4. Следите за LaTeX-панелью: она собирает систему в готовый к копированию вид, а также предупреждает, если список неравенств пуст.
5. Сохраните результат через `Сохранить график…`, если нужно получить изображение для отчёта или презентации.

## Работа с конфигурациями
- **Экспорт**: нажмите `Экспорт cfg…`, выберите каталог и имя файла. Внутри лежит JSON со списком неравенств, настройками области и коэффициентами функции.
- **Импорт**: `Импорт cfg…` читает ранее сохранённый файл и восстанавливает состояние. Неверный формат сопровождается сообщением с описанием ошибки.
- **Пример**: 
  ```json
  {
    "function": {"a": 1.0, "b": 1.0},
    "inequalities": [
      {"a": 1.0, "b": 1.0, "c": 6.0, "operator": "<="}
    ],
    "display": {
      "x": {"min": 0.0, "max": 10.0},
      "y": {"min": 0.0, "max": 10.0}
    }
  }
  ```
  Пустой список неравенств допустим, но график в этом случае не строится.

## Меню и горячие клавиши
- `Система → Добавить неравенство` — альтернатива кнопке в панели.
- `Система → Очистить` — удаляет все элементы списка; затем добавьте новые вручную.
- `Ctrl+Q` — выход из приложения.

## Советы
- Коэффициенты допускают дробные значения; шаг можно менять колёсиком мыши или вводом с клавиатуры.
- Чтобы построить примерную область из кода, используйте `Сбросить к примеру`, затем добавьте нужные элементы; кнопка очищает список и подготавливает его к заполнению.
- При сохранении графика рекомендуется формат PNG с DPI по умолчанию 300 для печати.
